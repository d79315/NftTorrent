# NftTorrent

Decentralized, peer-to-peer network enables real-time data processing and auto-scaling across a dynamic NFT data protocol.

With NftTorrent, you get a lightweight tool that stays out of your way.

**What you get**

- Decentralized, peer-to-peer network enables real-time

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/NftTorrent.git`
2. `cd NftTorrent`
3. Install in editable mode: `pip install -e .`

## Configuration

NftTorrent is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
